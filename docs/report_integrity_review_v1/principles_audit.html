Recommended wording improvements

Model choice: “LightGBM was used as the fixed tabular runtime-regression model. The experiment compared it with a family-median baseline. It did not compare alternative learned models or tune hyperparameters on the held-out test set; the recorded settings should not be interpreted as optimal.” The inspected training script fits one specified model. If earlier exploratory tuning occurred, disclose that separately rather than assuming the script proves it never happened.

Calibration assumptions: “Grouping keeps the three repetitions of each family/configuration pair in one split. This prevents repeat leakage but does not establish exchangeability across workload groups or new workloads. The nominal calibration level is therefore reported alongside observed coverage and the fixed-profile limitations.”

Reproducibility boundary: “Reported tables and plots can be traced to pinned compact evidence and generation scripts. Repeating the physical measurements additionally requires the retained raw records, generated inputs, recorded environment and experiment host. This report does not establish a fresh independent rerun.”

Encountered implementation problem: “A Windows checkout could change line endings in the saved LightGBM text model. The loader reads the model as text with newline normalization to avoid invalid stored tree-byte offsets; regression tests cover this compatibility fix.” This is supported by the loader comment and tests, and gives a concrete encountered problem rather than generic methodological prose.
